DARCY FLOW · migrar para o Firebase

EE Prof. Darcy Silveira Vaz · Colina/SP

Antes de começar

As telas, as senhas individuais, a aprovação do administrador, os relatórios e o funcionamento offline continuam iguais. Muda só o motor que guarda os dados, e o e-mail de confirmação passa a ser gratuito pelo Firebase.

1. Criar o projeto

  1. Abra console.firebase.google.com e entre com a conta Google da escola.
  2. Toque em Criar projeto, use o nome darcy-flow e aceite o ID sugerido.
  3. Desative o Google Analytics e confirme. Fique no plano Spark (gratuito).

2. Registrar o aplicativo web

  1. No projeto, toque no ícone </> (Web).
  2. Apelido darcy-flow-web, sem marcar Hosting agora.
  3. Copie o bloco firebaseConfig que aparece. É ele que você cola no sistema.
Esses valores são públicos (vão no navegador). Senha, token de serviço e chave de administrador nunca entram no código.

3. Ativar login por e-mail e senha

  1. Authentication → Começar → E-mail/senha → ativar → salvar.
  2. Em Templates, escolha Português do Brasil e revise o e-mail de verificação.

4. Criar o banco e publicar as regras

  1. Firestore Database → Criar banco → local southamerica-east1 → modo Produção.
  2. Aba Regras: cole o conteúdo de firebase/firestore.rules e publique.

5. Ligar o sistema ao projeto

  1. Abra o sistema e entre como administrador.
  2. Configurações → Firebase → cole a configuração → Salvar e testar.
  3. Toque em Migrar dados para o Firebase para enviar turmas, alunos, banheiros, cabines, movimentações, alertas e o resto.

O que depende do plano pago

  • Cloud Functions exigem plano Blaze. O sistema faz a lógica no navegador e o Firestore aplica as regras no servidor.
  • Envio de e-mail com domínio próprio e notificação com o app fechado também entram no Blaze, que tem cota gratuita mensal.
