## Aplicativo Android

Baixe `darcy-flow-1.7.apk` nesta mesma pasta e instale no aparelho. O aplicativo
funciona sem internet e sincroniza com a web quando há conexão.

## Sincronização

O painel envia e recebe dados do endpoint `darcySync` (Base44), coleção por coleção,
com resolução de conflito por registro mais recente.

## Dados

Demonstração com dados fictícios. Nenhuma câmera, microfone ou reconhecimento facial
é usado nas cabines.
