Regras do Firestore

DARCY FLOW · colar no console do Firebase

  1. Toque no botão azul abaixo para copiar as regras.
  2. Volte na aba Regras do Firestore, no console do Firebase.
  3. Clique dentro do editor, aperte Ctrl + A e depois Delete (no Mac: Cmd + A).
  4. Aperte Ctrl + V e confira: a primeira linha tem que ser rules_version = '2';
  5. Toque em Publicar.

Se o botão não copiar, clique dentro da caixa preta, aperte Ctrl + A e depois Ctrl + C.

Não cole direto do WhatsApp: o aplicativo costuma levar junto a palavra code e caracteres invisíveis, e é isso que faz o console recusar. Copiando desta página o texto vai limpo.
